协议内核：8 类契约（其余全部在协议外）

契约方向不可让步的内容
Module Manifest模块→系统发现自己：模块 id/版本、actions[]、events[]、支持的协议版本。/.well-known/asip
Actionagent→模块inputSchema / outputSchema / risk{level,reversible,money} / idempotency{keyFields} / preconditions / compensation
Domain Event模块→agent信封（id/type/subject/occurredAt/causation/correlation）+ 至少一次投递 + 可重放
Planagent→系统DAG steps + expectedDiff（dry-run 结果）+ 每步幂等键，可被人读懂、可被策略评估、可回放
Intent / Context / Confirm双向共驾三帧；声明式（open/focus/prefill/highlight/propose），不含 DOM 选择器
Grant控制平面agent 身份 × 模块 × action 白名单 + 配额；越权必须被模块侧也拒一次
Policy控制平面risk+context → auto | approve | deny；策略不可被 agent 读取改写，只能被请求评估
Audit Event系统→存储append-only、不可变、含 inputHash/结果/令牌用量/审批人；模块侧也独立记一份（对账用）
协议内（必须写死）
JSON 线格式 · 状态机 · 幂等/补偿语义 · 审计必产生 · 版本协商 · 错误码
协议外（永不规定）
数据库 · 消息中间件 · 鉴权实现 · 前端框架 · 部署形态 · LLM 供应商 · agent 内部规划算法
