去 dsh 里说这句话

对话只有一个入口：dsh 容器（127.0.0.1:3080）。本页不投递任何请求—— 同一句话从两个地方发出去，agent 会收到两条一样的指令。

打开 dsh agent 会先核库存，再决定是否开采购申请；要落单时 dsh 里会出选项卡片。

打不开 dsh（只显示 dsh web authentication required）不是链接坏了：dsh 的入口是它启动时打印的 带 ?token=… 的那条 URL，开一次才会种下 30 天的 cookie；之后这个地址直接可用。

页面不参与 Tenon-Version 协商、不要求 token；写操作只能由宿主签票后执行。
