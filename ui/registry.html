对话在哪

对话只有一个入口：dsh 容器（http://127.0.0.1:3080/）。它通过 MCP 读这张表 （mcp__tenon__registry_list），并在对话里用选项卡片让你决定「允许执行 / 驳回」。 本页不再提供输入框——同一个状态有两个对话入口，迟早会出现「在 A 页点过、在 B 页又点一次」。

打开 dsh 对话 →

如果打开后只有一行 dsh web authentication required，那不是链接坏了： dsh 的入口是启动时打印的 带 ?token=… 的那条 URL（token 每进程随机、 只存在内存里），访问它才会种下 30 天的 HttpOnly cookie；之后这个裸地址在同一个浏览器里直接可用。 本仓的 scripts/dsh-up.ps1 会把那条 URL 抓到 out/dev/dsh-url.txt 并打印出来。
